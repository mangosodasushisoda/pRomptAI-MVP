# 🚀 pRomptAI (MVP)
> **"Stop coding by blocks, start thinking in logic."** > スクラッチの「操作の難解さ」を排し、自然言語による対話を通じてプログラミング的思考（ロジック）をダイレクトに実行環境へ繋げる実験的プロジェクト。

---

## 💡 プロジェクトの背景 (Vision)
既存のビジュアルプログラミング（Scratch等）は、本来学ぶべき「論理の構築」の前に、特有のUI操作やブロックの組み合わせ方に習熟する必要がありました。本プロジェクトは、その「UIの壁」と「英語の壁」をAIで取り払い、初心者が**自分の母国語で考えたロジックがそのまま動く感動**を最短距離で提供することを目指しました。

---

## 🛠 技術スタックと設計思想

### 1. Local-First AI Architecture
* **LM Studio (Local LLM) 統合:**
  クラウドAIのAPIコスト問題を回避し、プライバシーとオフライン実行を担保。「金がない」という制約を、**「個人のPCリソースを最大限に活用するエッジコンピューティング」**という強みに転換。
* **Zero-Latency Design:** 通信制限に左右されないローカル環境での開発。

### 2. Natural Language Compilation (NLC)
* **直感的なJS変換:** ユーザーの日本語入力をAIがリアルタイムで解析。構文エラーに怯えることなく、`右に10動かす` といった口語表現を即座にJavaScript実行コードへトランスパイル。
* **Implicit Context Execution:**
  複雑な初期設定を隠蔽し、初心者が「本質的なロジック（どう動かしたいか）」だけに集中できるサンドボックス環境を提供。

# 📝 pRomptAI：初期構想メモ（Vision Document）

## 1. なぜ作るのか？ (Motivation)
* **既存ツールの壁:** プログラミング学習の定番「Scratch（スクラッチ）」に触れてみたが、正直、操作方法やブロックの意味が全然わからなかった。
* **言葉の壁:** プログラミングは英語が基本。最初から英語でつまずくのではなく、自分の使い慣れた「日本語」でロジックを組み立てたい。
* **AIとの共生:** AIが進化している今、人間が全部コードを書くのではなく、「やりたいこと」を伝えてAIにサポートしてもらう形が一番自然だと思った。

---

## 2. 実現したいこと (Core Concepts)
* **日本語プログラミング:**
  「右に動かす」「ジャンプする」といった口語体で指示を出し、それをAIが即座に動くプログラム（JavaScript）に変換する。
* **「ヒント」としてのAI:**
  AIに全部丸投げして作ってもらうのではなく、AIはあくまで「ヒント」を出すガイド役。自分で考える力を養うためのツールにする。
* **ローカル・ファースト:**
  API代などの「お金」をかけず、自分のPCのパワー（ローカルAI）を使って無料で、かつ安全に開発を進める。

---

## 3. 実装したかった理想の機能 (Feature Ideas)
* **ロードマップ提示:** やりたいことを伝えると、AIが「じゃあ、まずはこれを学ぼう」と道筋を示してくれる。
- **リアルタイム・アドバイス:** - 文法ミスをAIが分析してヒントを出す。
  - 遠回りな（効率の悪い）コードを書いていたら、もっといい方法を教えてくれる。
- **ステップアップ支援:** - 日本語のコードに慣れてきたら、本物のプログラミング言語（C++やRustなど）への移行をAIが手伝ってくれる。
- **共有プラットフォーム:** - 1週間で作ったゲームやアプリを、他のユーザーと簡単に見せ合える場所。

---

## 4. 開発における自分ルール (Guidelines)
* **AIに全自動でコードを書かせすぎない:** あくまで学習者が「自分で書く」ことを主役にする。AIは行き詰まった時の助っ人。
* **倫理的思考力を育てる:** 「どうしてこう動くのか？」という理屈をAIとの対話で理解できるようにする。

---

## 5. ぶつかった壁 (Challenges)
* **AIコンパイルの限界:** AIが作るプログラムの正確さを100%にするのが難しく、動かないコードが出てしまう問題。
* **開発コスト:** クラウドAIやサーバー維持費など、個人（中学生）では賄いきれない費用の問題。
