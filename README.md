# 🚀 pRomptAI (MVP)
> **"Stop coding by blocks, start thinking in logic."** > スクラッチの「操作の難解さ」を排し、自然言語による対話を通じてプログラミング的思考（ロジック）をダイレクトに実行環境へ繋げる実験的プロジェクト。

---

## 💡 プロジェクトの背景 (Vision)
既存のビジュアルプログラミング（Scratch等）は、本来学ぶべき「論理の構築」の前に、特有のUI操作やブロックの組み合わせ方に習熟する必要がありました。本プロジェクトは、その「UIの壁」と「英語の壁」をAIで取り払い、初心者が**自分の母国語で考えたロジックがそのまま動く感動**を最短距離で提供することを目指しました。

---

## 🛠 技術スタックと設計思想

### 1. Local-First AI Architecture
* **LM Studio (Local LLM) 統合:**
  クラウドAIのAPIコスト問題を回避し、プライバシーとオフライン実行を担保。「金がない」という制約を、**「個人のPCリソースを最大限に活用するエッジコンピューティング」**という強みに転換。
* **Zero-Latency Design:** 通信制限に左右されないローカル環境での開発。

### 2. Natural Language Compilation (NLC)
* **直感的なJS変換:** ユーザーの日本語入力をAIがリアルタイムで解析。構文エラーに怯えることなく、`右に10動かす` といった口語表現を即座にJavaScript実行コードへトランスパイル。
* **Implicit Context Execution:**
  複雑な初期設定を隠蔽し、初心者が「本質的なロジック（どう動かしたいか）」だけに集中できるサンドボックス環境を提供。

## 🧠 開発の記録 (Developer's Note)
このプロジェクトは、開発者が中学生の時に**「スクラッチが直感的に理解できなかった」**という実体験からスタートしました。

AIにコードを全て任せるのではなく、AIを「思考の翻訳機」として使う。
「実装が追いつかなかった」部分や「AIコンパイルの精度の壁」など、多くの技術的課題に直面しましたが、それは**AIと人間が共創する次世代のプログラミング教育**における本質的な問い（AIにどこまで委ねるか）を浮き彫りにしました。

## 🛠 実行方法
1. LM Studio等のローカルサーバーを起動。
2. 本リポジトリの `index.html` をブラウザで開く。
3. AIにやりたいことを伝え、コードが走る快感を体験する。
